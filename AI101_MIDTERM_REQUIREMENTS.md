ALVERNIA UNIVERSITY · AI 101

## Midterm project: a useful AI-assisted prototype

Create a small webpage or software prototype about your interests. AI must contribute to the development process, and you must explain, verify and disclose that contribution. A live AI API is optional.

### Minimum scope

- One named audience and one clearly stated need.
- Two or three working features, including one improvement tracked by an issue and pull request.
- A readable README with run instructions and known limitations.
- At least five recorded tests, including a failure or edge case. If no failure occurs, explain one limitation you investigated.
- An AI Use Note identifying tool, purpose, representative prompts, student changes, verification and limitations.

### Project choices

- Campus tour: selected stops, sourced descriptions and a category filter. Cesium is optional.
- Study helper: topic selection, practice prompts and answer feedback.
- Creative portfolio: labeled generated media, project descriptions and a filter.
- Hiking information guide: sourced locations, filters and clear limitations. Do not claim verified route safety from a map.
- Resource directory: search, categories and source links. Avoid collecting sensitive information.

### Submission

Submit the project URL if hosted, repository link or source ZIP, README, issue and PR evidence, test log, before/after screenshots and AI Use Note. Ensure the instructor can access private work. Prepare a five-minute demonstration followed by questions: audience, working features, AI-assisted change, evidence and limitation.

### Project rubric: 100 points

| Criterion | Points | Full-credit evidence |
|---|---:|---|
| Audience and scope | 15 | Specific need and feasible features |
| Working prototype | 25 | Required features work in the demonstrated version |
| Issue and review process | 20 | Clear criteria, reviewed change and traceable revision |
| Testing and evaluation | 20 | Five actual tests with evidence and limitations |
| Explanation and AI disclosure | 20 | Student explains decisions and documents AI use |

Partial credit reflects incomplete evidence or behavior. Agent access, paid subscriptions and visual complexity do not earn extra points. The manual route uses the same rubric. Due dates and the applicable grade category appear in Canvas; this rubric does not alter syllabus category weights.
